# Yatube API

API для социальной сети Yatube с функционалом публикаций, комментариев, подписок и тематических групп.

## Возможности
- Полный CRUD для постов и комментариев
- Подписки на пользователей
- Тематические группы
- Аутентификация через JWT-токены
- Автоматическая документация (ReDoc)
